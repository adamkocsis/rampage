# Package index

## Ramp functions and tiepoint data

Primary functions to create color ramps.

- [`expand()`](https://adamtkocsis.com/rampage/reference/expand.md) :
  Create a calibrated color ramp object from color-tiepoint data.frames
- [`trimramp()`](https://adamtkocsis.com/rampage/reference/trimramp.md)
  : Trimming a calibrated color ramp object.

## Plotting applications

Functions to visualize color ramps.

- [`plot(`*`<calibramp>`*`)`](https://adamtkocsis.com/rampage/reference/plot.md)
  [`rampplot()`](https://adamtkocsis.com/rampage/reference/plot.md) :
  Visualize a calibrated color ramp
- [`colorpoints()`](https://adamtkocsis.com/rampage/reference/colorpoints.md)
  : Heatmap with colored points
- [`ramplegend()`](https://adamtkocsis.com/rampage/reference/ramplegend.md)
  : Create a heatmap legend based on calibrated color ramp values

## Example data

Color ramp palettes, ramp tiepoint data.frames and expanded calibrated
ramps.

- [`topos`](https://adamtkocsis.com/rampage/reference/topos.md) :
  Topographic color palettes with tiepoints
- [`bathymetry`](https://adamtkocsis.com/rampage/reference/bathymetry.md)
  : Bathymetric color palettes with tiepoints
- [`paleomap`](https://adamtkocsis.com/rampage/reference/paleomap.md) :
  Topographic gradient map color map of the PALEOMAP project
- [`gradinv()`](https://adamtkocsis.com/rampage/reference/ramps.md) :
  Color gradient ramps

## Auxilliary functions

Example data for ramp tiepoints and some color palettes.

- [`limit()`](https://adamtkocsis.com/rampage/reference/limit.md) :

  Limit range of values in a `SpatRaster` object
